## Headline

This week, the POC graduated from a monolithic chatbot-style pipeline toward an agentic architecture: introduced a **model-agnostic AI adapter**, a **mandatory PII/PHI redaction layer**, and a dedicated **Dispatcher agent** with a pinned JSON schema and few-shot examples following Anthropic's customer-support prompting pattern. These three new modules run alongside the existing `aiMiddleware` without changing user-facing behavior, enabling a safe shadow-evaluation in Week 2 before we cut over. Also installed the full methodology as project skills so every future change stays aligned with the 100-pt judging rubric.

## Risks and blockers

- **No eval set yet.** The dispatcher works but is unmeasured. Acceptable for Week 1 (infrastructure) but is the hard blocker for shipping in Week 2.
- **OpenAI-only today.** The Anthropic branch in `client.ts` is stubbed; activating it needs `@anthropic-ai/sdk` + an `ANTHROPIC_API_KEY`. Plan: flip in Week 2 once the eval set exists so we can compare providers objectively.
- **POC uses in-memory store.** A process restart mid-demo would reset dashboard counters. Will persist to disk or a lightweight DB in Week 4 hardening.
